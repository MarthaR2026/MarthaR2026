   https://github.com/MarthaR2026/qa-project-Urban-Routes-es

2. 🛒 Urban Grocers — API Test Automation
   https://github.com/MarthaR2026/qa-project-Urban-Grocers-app-es

Suite de pruebas automatizadas para validar las reglas de negocio y límites de entrada en el endpoint de creación de kits de usuario (POST /api/v1/kits).

Stack: Python · Pytest · Requests · Postman · REST/JSON

Aspectos clave:

Automatización de 9 escenarios positivos y negativos aplicando análisis de valores límite (1, 511 y 512 caracteres), caracteres especiales, espacios, campos vacíos, parámetros faltantes y tipos de datos inválidos.

Gestión dinámica de creación de usuarios y autenticación mediante encabezados Authorization: Bearer <token>.

Hallazgos: Detección y documentación de 4 discrepancias de validación en el backend (respuestas HTTP 201 y 500 en escenarios inválidos donde se esperaba código 400).
